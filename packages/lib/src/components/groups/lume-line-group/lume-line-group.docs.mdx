# Lume line group

Transforms dataset values into SVG lines and data points rendered inside a `LumeChart`.

## Properties

| Name           | Type                                                           | Default     | Description                                                                                 |
| -------------- | -------------------------------------------------------------- | ----------- | ------------------------------------------------------------------------------------------- |
| `data`         | `Data`                                                         | Required    | The data to plot.                                                                           |
| `options`      | `Options`                                                      | `undefined` | A set of chart options. Refer to `ChartOptions` in `LumeChart`.                             |
| `xScale`       | `ScaleGenerator` or `ScaleBand<string>` or `ScaleBand<number>` | `null`      | A d3 scale or a scale generator function to override the default X scale.                   |
| `yScale`       | `ScaleGenerator` or `ScaleLinear<number, number>`              | `null`      | A d3 scale or a scale generator function to override the default Y scale.                   |
| `hoveredIndex` | `Number`                                                       | `-1`        | The index being hovered. Required if you want to enable hovering in the index.              |
| `transition`   | `boolean`                                                      | `true`      | Whether the lines should animate.                                                           |
| `classList`    | `string` or `Array<string>`                                    | `[]`        | A class or array of classes to apply to the chart group elements, such as bars, lines, etc. |
| `withPoints`   | `boolean`                                                      | `true`      | Whether the group should render points in addition to lines.                                |

## Events

| Event         | Payload                                                        | Description                  |
| ------------- | -------------------------------------------------------------- | ---------------------------- |
| `line-click`  | `{ index: number, datasetIndex: number, event: PointerEvent }` | Fired upon clicking a line.  |
| `point-click` | `{ index: number, datasetIndex: number, event: PointerEvent }` | Fired upon clicking a point. |
