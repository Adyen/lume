# Lume point

<Canvas of={LumePointStories.Basic} />

Draws an SVG circle to highlight a data point, such as when hovering over a point on a line chart.

## Properties

| Name     | Type      | Default  | Description                                                                                 |
| -------- | --------- | -------- | ------------------------------------------------------------------------------------------- |
| `x`      | `number`  | Required | The horizontal coordinate to position the point.                                            |
| `y`      | `number`  | Required | The vertical coordinate to position the point.                                              |
| `color`  | `string`  | `'01'`   | Color to use, representing an index to one of the available Lume colors.                    |
| `radius` | `number`  | `4`      | The radius (in pixels) of the point. If accompanying a line, should double its width value. |
| `active` | `boolean` | `false`  | Whether the point is active.                                                                |

## Events

| Event   | Payload        | Description                    |
| ------- | -------------- | ------------------------------ |
| `click` | `PointerEvent` | Fired upon point circle click. |
